# Abfahrtstafel – Kurzanleitung

Die Tafel zeigt, wann Bus und Bahn an deiner Haltestelle abfahren. Sie läuft von allein, du musst sie nur einmal einrichten.

## Einrichten (einmalig, ca. 5 Minuten)

1. **Einstecken.** Netzteil in die Steckdose, Kabel in die Tafel. Auf dem Display steht „Hallo! Kurz einrichten“.
2. **WLAN verbinden.** Den Code auf dem Display mit der Handy-Kamera scannen, oder in den WLAN-Einstellungen des Handys
   das WLAN **Abfahrtstafel-…** wählen. Es öffnet sich eine Seite: **WLAN einrichten** antippen, dein WLAN antippen,
   dein WLAN-Passwort eingeben, **Verbinden**.
3. **Haltestelle wählen.** Das Handy wieder mit deinem normalen WLAN verbinden. Den neuen Code auf dem Display scannen
   (oder im Browser **abfahrt.local** eingeben). Unter **Einstellungen** die Haltestelle suchen, antippen, **Speichern**.

Nach einer Minute erscheinen die Abfahrten. Fertig.

## So liest du die Tafel

| Anzeige | Bedeutung |
|---|---|
| **5 min** | fährt in 5 Minuten |
| **jetzt** | fährt gerade ab |
| **14:32** | fährt erst in über einer Stunde |
| **rote Minuten**, daneben eine durchgestrichene Uhrzeit | Verspätung: durchgestrichen ist die geplante, darunter die neue Zeit |
| durchgestrichen, „fällt aus“ | diese Fahrt fällt aus |
| gelbe Leiste „Stand 14:20 Uhr“ | die Tafel hat gerade keine neuen Daten und zeigt die letzten bekannten |

Nachts schaltet die Tafel auf gedämpftes Bernstein-Licht oder geht ganz aus, je nach Einstellung.

## Wenn etwas nicht stimmt

| Auf dem Display | Was tun |
|---|---|
| „Keine WLAN-Verbindung“ / „WLAN nicht erreichbar“ | Ist der Router an? Einfach warten, die Tafel verbindet sich von selbst wieder. |
| „Fahrplandaten nicht erreichbar“ | Nichts tun. Die Tafel versucht es selbst wieder. |
| „Neue Version wird installiert“ | **Stecker nicht ziehen.** Dauert etwa eine Minute. |
| Neuer Router oder neues WLAN-Passwort | Nach ein paar Minuten zeigt die Tafel wieder einen Code: wie bei Schritt 2 neu verbinden. |
| Bildschirm schwarz | Nachtzeit? Sonst Stecker kurz ziehen und wieder einstecken. |

Hilft das alles nicht: **Stecker ziehen, 10 Sekunden warten, wieder einstecken.**

## Einstellungen ändern

Im Browser **abfahrt.local** öffnen (Handy im selben WLAN). Dort lassen sich Haltestelle, Helligkeit, Nachtzeit und
Anzahl der Zeilen ändern. Unter **Update** gibt es neue Versionen – einfach auf „Update installieren“ tippen.

## Alles zurücksetzen

Den kleinen Knopf **BOOT** an der Tafel (im laufenden Betrieb) **10 Sekunden gedrückt halten**. Danach startet die Tafel
wie neu und du richtest sie wieder mit Schritt 1–3 ein.
