wannbus

Firmware installieren

Spielt die neueste Version per USB-Kabel auf die Tafel – für die Erstinstallation oder wenn die Tafel gar nicht mehr startet. Normale Updates laufen bequem über die Weboberfläche der Tafel.

Version wird geladen …
  1. Tafel mit einem USB-C-Datenkabel an diesen Computer anschließen. Reine Ladekabel funktionieren nicht.
  2. Auf Installieren klicken und im Fenster den Eintrag mit „USB“ bzw. „JTAG“ wählen.
  3. Nach etwa einer Minute startet die Tafel und öffnet das WLAN wannbus-XXXX zur Einrichtung.
Dieser Browser kann nicht per USB installieren. Bitte Chrome oder Edge am Computer verwenden (nicht am Handy). Installieren geht nur über HTTPS – bitte diese Seite über GitHub Pages öffnen.
Gut zu wissen

Die Firmware wird komplett neu geschrieben: WLAN-Zugangsdaten und Einstellungen gehen dabei verloren. Startet die Tafel gar nicht mehr, vor dem Installieren den BOOT-Taster gedrückt halten, kurz RESET drücken und BOOT loslassen.
